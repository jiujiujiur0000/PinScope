# PinScope v1.0 - GPIO 引脚跳变监视器

PinScope 是一款基于 Python 3 与 PyQt5 开发的高颜值、轻量级 GPIO 引脚跳变监视桌面应用。专为嵌入式硬件调试、单片机 GPIO 状态监控及电平跳变捕获场景设计。

---

## 🌟 核心特性

- **多引脚实时监视**：支持 `PA0 ~ PA15` 和 `PB0 ~ PB15` 共 32 个 GPIO 引脚的实时电平监控与跳变统计。
- **跳变捕获与锁存**：当监测到引脚电平发生跳变（如高低电平翻转或脉冲输入）时，自动触发报警级视觉锁存高亮提示，并累计跳变次数。
- **灵活过滤与勾选**：左侧提供引脚筛选器，支持全选、清空和自定义多选，仅展示关心的引脚卡片。
- **智能串口通信**：自动侦测系统串口设备，支持多波特率选择与串口记忆。支持通过标准串口或 STDIN 实时接收硬件状态更新。
- **多格式数据解析**：
  - **16位 HEX 掩码**：如 `0x0005`，自动映射解析 `PA0 ~ PA15` 电平状态。
  - **键值对文本**：如 `PA2: 1` 或 `PB8: 0`，精准更新特定引脚电平。
- **深浅色主题自适应**：内置自适应系统主题检测，支持跟随系统、深色模式及浅色模式无缝切换。
- **模拟脉冲测试与单键重置**：内置模拟脉冲触发器方便无硬件连接时的界面调试；支持单引脚或全局重置清零。

## 🛠️ 环境依赖与安装

- **Python**: 3.6+
- **PyQt5**: GUI 框架
- **PySerial**: 串口通信支持 (可选，未安装时回退至系统设备节点/STDIN)

### 安装命令

```bash
pip install PyQt5 pyserial
```


## 🛰️ 串口与数据格式规范

当连接串口或通过管道输入时，PinScope 自动逐行解析以下格式的数据：

1. **HEX 掩码格式（16位）**
   - 示例：`0x0005`（二进制 `0000 0000 0000 0101`）
   - 说明：按位依次映射更新 `PA0 ~ PA15` 电平状态。

2. **引脚电平键值对格式**
   - 示例：`PA2: 1` 或 `PB8: 0`
   - 说明：直接更新目标引脚为对应的 1 (高电平) 或 0 (低电平)。
