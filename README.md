# PinScope - GPIO 引脚状态监视与调试助手

PinScope 是一款基于 Python 3 和 PyQt5 开发的 GPIO 引脚状态监视与硬件诊断桌面工具，专为嵌入式开发调试场景设计。

---

## 概述

在单片机与外设调试过程中，PinScope 用于快速定位硬件线路与软件逻辑故障：

* **硬件故障诊断**：直观检测按键、传感器等输入设备的电平跳变，区别硬件电路故障与软件代码问题。
* **瞬态跳变捕获**：自动锁存电平变化并累计跳变次数，防止遗漏毫秒级脉冲信号。
* **双向控制测试**：支持通过界面发送指令控制单片机输出引脚（如置高/置低或触发脉冲），验证外设响应。
* **多通道逻辑示波**：提供多路 GPIO 电平随时间变化的波形图，便于分析信号时序。

---

## 功能特性

- **多引脚监视**：支持 32 通道 GPIO（PA0~PA15，PB0~PB15）电平实时监控。
- **状态胶囊展示**：提供 key-value 分栏与 `LOW (0)` / `HIGH (1)` 状态显示。
- **双向串口通信**：支持真实串口收发（115200bps），未连接硬件时自动提供离线模拟功能。
- **零循环负担接入**：下位机模块基于 SysTick 定时器自动采样，主循环无需编写采样代码。

## 快速开始

### 步骤 1：STM32 硬件端接入

将 `mcu/pin_scope.h` 与 `mcu/pin_scope.c` 加入 STM32 工程，在 `main.c` 中添加初始化调用：

```c
/* USER CODE BEGIN Includes */
#include "pin_scope.h"
/* USER CODE END Includes */

int main(void)
{
    /* 硬件初始化... */

    /* USER CODE BEGIN 2 */
    PinScope_Init(); // 初始化串口1 (115200bps, PA9-TX, PA10-RX) 与 SysTick 定时采样
    /* USER CODE END 2 */
}
```

---

### 步骤 2：电脑端软件环境与启动

#### 1. 安装依赖
```bash
pip install PyQt5 pyserial
```

#### 2. 运行 PinScope
```bash
python3 pin_scope.py
```

---

### 步骤 3：界面操作说明

1. **连接串口**：选择目标串口（如 `COM3` 或 `/dev/ttyUSB0`），波特率设为 `115200`，点击 **连接串口**。
2. **过滤引脚**：在左侧列表中勾选需要监视的引脚。
3. **脉冲测试**：点击卡片上的 **脉冲** 按钮，向单片机下发 300ms 高电平脉冲指令。
4. **示波器**：点击 **多通道波形示波器** 按钮，打开独立波形窗口查看实时时序。
